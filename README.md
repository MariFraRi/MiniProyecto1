# 🎓 Mini Proyecto 1 — Predicción de Abandono y Rendimiento Académico

## Descripción | Description

**ES:** Este proyecto aplica el algoritmo **K-Nearest Neighbors (KNN)** para predecir el abandono escolar y el rendimiento académico de estudiantes. Se trabajó con un proceso completo de ciencia de datos: exploración de datos, preprocesamiento, entrenamiento del modelo y evaluación de resultados.

*This project applies the **K-Nearest Neighbors (KNN)** algorithm to predict student dropout and academic performance. The full data science pipeline was followed: data exploration, preprocessing, model training, and evaluation.*
